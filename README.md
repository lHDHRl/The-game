# Tower Stack

Браузерная игра про постройку башни из блоков с физикой. Курс **«Проектирование и разработка игровых приложений»**, практика и домашняя работа №1 ([`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md)).

**Играть:** https://lhdhrl.github.io/The-game/

Стек: **TypeScript + Phaser 4 + Matter.js + Vite + GitHub Pages**.

## Об игре

> Игрок отпускает блоки с качающегося крана, чтобы построить башню как можно выше, пока ему мешают инерция, сужающиеся блоки и ускоряющийся кран.

- Над башней качается кран с блоком. Игрок отпускает блок, и тот падает на башню по законам физики.
- Блок летит по инерции: у него остаётся половина скорости крана, поэтому отпускать нужно с упреждением.
- С каждым этажом блоки сужаются (со 130 до 70 px), а кран качается быстрее.
- Верхние 6 этажей «живые» и могут сдвигаться и падать. Нижние замораживаются, чтобы высокая башня оставалась устойчивой.

### Управление

| Действие | Клавиша |
|---|---|
| Отпустить блок | Клик по экрану / Пробел |
| Начать заново после проигрыша | Клик / Пробел / R |

### Очки и проигрыш

- **+1** за каждый поставленный этаж.
- **+1 бонус «ИДЕАЛЬНО!»**, если блок встал не дальше чем в 6 px от центра предыдущего.
- **Проигрыш:** любой блок, свалившийся ниже пьедестала. На экране появится «Блок упал!» или «Башня рухнула!», а также счёт и рекорд.
- Рекорд сохраняется в браузере (`localStorage`).

Все игровые параметры (размеры, скорость крана, инерция, допуск «идеально» и т. д.) вынесены в константы в начале `src/game/GameScene.ts`.

## Запуск

Нужен **Node.js 22 LTS** (или Node.js >= 20.19).

```bash
npm install
npm run dev
```

Игра откроется по адресу, который напечатает Vite (обычно `http://localhost:5173/`).

Проверка production-сборки:

```bash
npm run typecheck
npm run build
npm run preview
```

## Публикация

После push в `main` workflow `.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages (в **Settings → Pages → Source** выбрано **GitHub Actions**).
